# Matheus | DEV

## 🌐 Acesse o portfólio

https://matheus-santana-dev.github.io/portfolio/

## 👨‍💻 Sobre o projeto

Este projeto foi desenvolvido como meu portfólio pessoal, com o objetivo de apresentar minha formação, conhecimentos em tecnologia, projetos desenvolvidos e informações de contato.

O site possui layout responsivo, adaptado para computadores, tablets e dispositivos móveis, além de um menu mobile com interação em JavaScript e um formulário de contato integrado ao Web3Forms.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages
- Web3Forms
